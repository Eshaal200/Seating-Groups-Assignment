# Seating-Groups-Assignment
This repo is for the assignment Seating Groups

in the class GroupStudents first I implemented the method InsertionSort to sort the array from smallest to biggest (students ascending skill levels). then I implemeted the method groupingStudents by first splitting the array in 2 equals halves (a and b). then I use the 
method Math.abs, to make sure the numbers are postive. I subtract b from a to find the difference. then I add that to a variable called totalDifference. I print the differences to the terminal and totalDifference.

the time complexity for insertion sort O(n^2) - for loop + while loop
the time complexity for groupingStudents is O(n) - one for loop
total time complexity = O(n^2)
